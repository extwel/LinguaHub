# Individual Reflection — extwel

## 1. Which pattern did you implement, and what would the code look like without it?

В проекте LinguaHub я реализовал паттерн Factory Method (Фабричный метод). Он позволяет создавать разные типы курсов, например языковые курсы и курсы подготовки к экзаменам, не привязываясь напрямую к конкретным классам. Без этого паттерна создание курсов происходило бы непосредственно в коде с использованием условий и операторов `new`, что усложнило бы добавление новых типов курсов и поддержку проекта.

## 4. Which pattern would you remove if you started over? Why?

Совместный ответ (extwel и Aniyar1):

Если бы мы начинали проект заново, мы бы в первую очередь пересмотрели необходимость использования паттерна Facade. Он упрощает взаимодействие между несколькими сервисами, однако на текущем этапе проекта его использование может быть избыточным. Мы бы добавляли его только тогда, когда логика взаимодействия сервисов стала бы достаточно сложной и действительно требовала отдельного фасада.
