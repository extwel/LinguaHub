
# ADR-0002: Design Pattern Selection for LinguaHub

- Status: Accepted
- Deciders: LinguaHub Development Team

## Context

LinguaHub — приложение для поиска, покупки
и прохождения языковых курсов.

Для повышения качества архитектуры необходимо
использовать паттерны проектирования, которые
решают реальные проблемы проекта.

При выборе паттернов учитываются простота,
расширяемость, тестируемость и принцип YAGNI.

## Options considered

### Selected patterns

1. Factory Method — создание различных типов курсов.
2. Strategy — использование различных алгоритмов скидок.
3. Observer — уведомление после регистрации на курс.
4. State — управление состояниями регистрации.
5. Facade — упрощение оформления покупки.

Repository используется отдельно как архитектурный
паттерн для доступа к данным.

### Rejected patterns

#### Abstract Factory

Преимущество: создание семейств связанных объектов.

Причина отказа: в LinguaHub отсутствует необходимость
создавать семейства связанных объектов.
Factory Method достаточно для создания типов курсов.

#### Builder

Преимущество: пошаговое создание сложных объектов.

Причина отказа: существующие объекты курсов
не требуют сложного многоступенчатого создания.

#### Mediator

Преимущество: централизованное управление
взаимодействием между компонентами.

Причина отказа: текущие взаимодействия между
компонентами не требуют отдельного посредника.

## Decision

Для текущей версии LinguaHub выбраны:

- Factory Method.
- Strategy.
- Observer.
- State.
- Facade.

Repository применяется для отделения бизнес-логики
от реализации хранения данных.

Abstract Factory, Builder и Mediator не используются
согласно принципу YAGNI.

## Consequences

### Positive

- Уменьшение связанности компонентов.
- Упрощение расширения функциональности.
- Разделение ответственности между классами.
- Возможность отдельного тестирования паттернов.
- Упрощение пользовательского интерфейса.

### Negative

- Увеличение количества классов и интерфейсов.
- Необходимость поддерживать документацию.
- Дополнительная сложность при изучении проекта.
